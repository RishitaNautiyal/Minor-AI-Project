# OffGrid – AI-Powered Digital Safety Platform

## 1. Project Overview

OffGrid is a digital safety platform designed to help users
identify potentially harmful online content using Artificial
Intelligence and Machine Learning.

The project demonstrates the application of AI in deepfake
image detection and suspicious message detection.

## 2. Main Features

1. AI Deepfake Detection
   - Analyses uploaded images using a pretrained AI model.
   - Provides real/fake classification with confidence scores.

2. AI Scam Checker
   - Analyses suspicious messages and URLs.
   - Uses Machine Learning and text-processing techniques.

3. User Authentication
   - Provides login and registration functionality.

4. Digital Safety Dashboard
   - Provides access to online safety features and activity
     information.

## 3. AI and Machine Learning Techniques

- Image Classification
- TF-IDF Text Feature Extraction
- Logistic Regression
- Rule-Based Scam Analysis

## 4. Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Hugging Face
- Scikit-learn
- Pandas
- Firebase

## 5. Project Objective

The main objective is to demonstrate how Artificial
Intelligence can be applied to improve digital safety by
identifying potentially manipulated images and suspicious
online messages.

## 6. Project Setup

Install the required Python packages:

pip install -r requirements.txt

Configure the required environment variables in a local
.env file using .env.example as a guide.

Run the application using:

python server.py

## 7. Applications

- Deepfake image awareness
- Online scam detection
- Digital safety awareness
- Identification of suspicious online messages

## 8. Limitations

AI predictions are not always 100% accurate. Results should
be treated as estimates and not as definitive proof.
